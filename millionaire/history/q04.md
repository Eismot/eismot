## Q3: B / That compiled high-level code could compete with hand-written machine code

IBM describes skeptics who doubted that compiled high-level programs could be as efficient as hand-crafted machine code. The Fortran team's optimizing compiler produced code close enough to hand-written performance to help change that perception. This does not assert that generated code always beats hand-written code.

[Source](https://www.ibm.com/history/fortran)

## A / Biological cells and computers communicating over a network

Kay recalls thinking of objects as biological cells or individual computers on a network, communicating only through messages. The question concerns his stated inspiration, not a required implementation architecture.

[Source](https://www.purl.org/stefan_ram/pub/doc_kay_oop_en)
