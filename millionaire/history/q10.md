## Q9: A / Atomically record a unique event ID and apply the effect in the same transaction, skipping IDs already recorded

A database-enforced unique event ID and the effect in one transaction prevent duplicate application while keeping the marker and effect consistent. Acknowledge after commit and retain deduplication records for the relevant replay window. External payment APIs need their own idempotency strategy; this answer only covers the stated database-local effect.

[Source](https://microservices.io/post/microservices/patterns/2020/10/16/idempotent-consumer.html)

## B / Its C implementation was translated automatically into Go

The Go FAQ says the gc compiler was originally written in C and translated automatically into Go for Go 1.5. This is a self-hosting milestone, not evidence that the original compiler was written in Go. See 'What compiler technology is used to build the compilers?'.
