## Q9: C / Visit each row from left to right before the next row

Row-major storage places consecutive elements of a row next to each other. Traversing within each row usually uses cache lines more effectively. Actual speed still depends on dimensions, cache behavior, compiler transformations, and hardware; measure it.

[Source](https://en.cppreference.com/w/c/language/array.html)

## B / A database UNIQUE constraint on the email column

A UNIQUE constraint makes the database enforce uniqueness across concurrent writes. An application-level check alone has a check-then-act race. The application must still handle the rejected insert; case folding and email normalization are separate design decisions.

[Source](https://www.postgresql.org/docs/current/ddl-constraints.html#DDL-CONSTRAINTS-UNIQUE-CONSTRAINTS)
