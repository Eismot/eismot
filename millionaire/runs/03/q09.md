## Q8: C / Visit each row from left to right before the next row

Row-major storage places consecutive elements of a row next to each other. Traversing within each row usually uses cache lines more effectively. Actual speed still depends on dimensions, cache behavior, compiler transformations, and hardware; measure it.

[Source](https://en.algorithmica.org/hpc/cpu-cache/cache-lines/)

## C / Fault-tolerant computers for aircraft control

Lamport identifies SIFT as NASA-funded research into reliable aircraft-control computers. He connects that work to the formulation and solutions of the Byzantine agreement problem. The generals story made the underlying fault model memorable; it was not the original application.

[Source](https://lamport.azurewebsites.net/pubs/pubs.html)
