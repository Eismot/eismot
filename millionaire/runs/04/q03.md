## Q2: A / C with Classes

Stroustrup identifies C with Classes as the original name. Rick Mascitti later suggested C++, using C's increment operator in the name.

## B / Monty Python's Flying Circus

The official Python FAQ says van Rossum was reading scripts from Monty Python's Flying Circus and wanted a short, distinctive, slightly mysterious name.

[Source](https://docs.python.org/3/faq/general.html#why-is-it-called-python)
