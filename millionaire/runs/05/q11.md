## Q10: C / The infected compiler recognizes compiler source and reinserts the attack into its successor

Thompson describes a compiler that inserts a backdoor into login code and also reproduces the compiler modifications when compiling its own source. Removing the malicious source changes is insufficient if the rebuilding compiler binary remains compromised.

## B / Its C implementation was translated automatically into Go

The Go FAQ says the gc compiler was originally written in C and translated automatically into Go for Go 1.5. This is a self-hosting milestone, not evidence that the original compiler was written in Go. See 'What compiler technology is used to build the compilers?'.

[Source](https://go.dev/doc/faq)
