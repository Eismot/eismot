## Q4: D / Inject a clock and use a fixed clock in the test

An injected clock lets the test choose the time explicitly. Sleeps, retries, and longer timeouts do not remove dependence on wall-clock time. Other nondeterministic inputs may still need control.

## C / The behavior is undefined

Accessing an object through a null pointer has undefined behavior. A crash is common, but neither a segmentation fault nor an exception is guaranteed; compiler optimizations can produce other outcomes.

[Source](https://en.cppreference.com/w/cpp/language/ub.html)
