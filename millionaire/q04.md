## Q3: A / WHERE

WHERE filters input rows; HAVING filters groups after grouping. This describes query semantics, not a promise about the database optimizer's physical execution order.

## D / Inject a clock and use a fixed clock in the test

An injected clock lets the test choose the time explicitly. Sleeps, retries, and longer timeouts do not remove dependence on wall-clock time. Other nondeterministic inputs may still need control.

[Source](https://learn.microsoft.com/en-us/dotnet/standard/datetime/timeprovider-overview)
