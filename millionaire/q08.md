## A / git revert COMMIT

git revert records a new commit that reverses a specified commit's changes. It can encounter conflicts. Reverting a merge also requires choosing a mainline parent; reset, restore, and clean do not provide the described operation.

[Source](https://git-scm.com/docs/git-revert)
