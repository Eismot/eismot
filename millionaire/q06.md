## Q5: C / The behavior is undefined

Accessing an object through a null pointer has undefined behavior. A crash is common, but neither a segmentation fault nor an exception is guaranteed; compiler optimizations can produce other outcomes.

## B / Reassigning config to another object

const prevents reassignment of the binding. It does not freeze the referenced object, so the properties of this ordinary object can still be changed, added, or deleted.

[Source](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/const)
