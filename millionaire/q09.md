## A / To access Amoeba system calls beyond what shell commands exposed

The Python FAQ explains that Amoeba system calls were not easily accessible from shell scripts. Van Rossum wanted an extensible language, influenced by ABC, that could reach those interfaces rather than rely only on shell commands.

[Source](https://docs.python.org/3/faq/general.html#why-was-python-created-in-the-first-place)
