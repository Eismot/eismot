## C / Visit each row from left to right before the next row

Row-major storage places consecutive elements of a row next to each other. Traversing within each row usually uses cache lines more effectively. Actual speed still depends on dimensions, cache behavior, compiler transformations, and hardware; measure it.

[Source](https://en.cppreference.com/w/c/language/array.html)
