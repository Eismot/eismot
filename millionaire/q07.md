## Q6: C / The behavior is undefined

Accessing an object through a null pointer has undefined behavior. A crash is common, but neither a segmentation fault nor an exception is guaranteed; compiler optimizations can produce other outcomes.

[Source](https://en.cppreference.com/w/cpp/language/ub.html)

## B / A compromised compiler can insert malicious code during the build

In Reflections on Trusting Trust, a modified compiler recognizes selected source and inserts an attack. Reviewing the target source alone therefore cannot establish the behavior of the resulting executable when the toolchain is compromised. This does not imply that independent verification is impossible.

[Source](https://aeb.win.tue.nl/linux/hh/thompson/trust.html)
